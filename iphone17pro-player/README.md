# iPhone 17 Pro 专用播放器（PWA）

横屏专用的渐进式网页应用（PWA）视频播放器，视频来源为 iOS 系统相册与文件 App，无需安装任何原生应用。

## 功能

- 横屏专用：安装后强制横屏显示；竖屏时提示旋转，也可一键“强制横屏（画面旋转）”
- 来源：相册 / 文件（点击后由 iOS 系统选择器提供，可在相册与文件之间切换）
- 播放 / 暂停
- 前进 / 后退：每按一次 ±10 秒（按住可连续快进 / 快退）
- 锁屏：锁定后隐藏全部控制键，仅保留锁屏徽标；长按徽标 0.65 秒解锁，防止误触
- 长按加速：按住画面任意位置临时加速播放（默认 1.5 倍），松手恢复原速
- 长按拖动进度条：按住或拖动进度条时显示浮动时间标签（时:分:秒），松手精确跳转
- 播放速度：0.75× / 1× / 1.25× / 1.5×，可循环切换或在设置中选择
- 全屏播放：支持浏览器全屏与 iPhone 原生全屏
- 离线可用：安装后打开首页无需网络

## 在 iPhone 上安装

1. 把本目录部署到任意 HTTPS 静态服务器（例如 GitHub Pages、Vercel、Netlify、自己的服务器），或用局域网 HTTP 服务器临时体验（PWA 安装与离线缓存需要 HTTPS；`localhost` 除外）。
2. 用 iPhone 的 Safari 打开网址。
3. 点击 Safari 的「分享」按钮 →「添加到主屏幕」→ 添加。
4. 从主屏幕图标打开，即为全屏、横屏专用模式。

## 电脑端本地预览

```bash
cd iphone17pro-player
python -m http.server 8080
```

然后浏览器打开 `http://localhost:8080`。电脑端可以直接把视频文件拖进窗口测试。

## 操作说明（iPhone 手势）

| 操作 | 效果 |
| --- | --- |
| 点击画面 | 显示 / 隐藏控制栏 |
| 按住画面 | 临时 1.5× 加速（可在设置中调整） |
| 点击 ±10 按钮 | 前进 / 后退 10 秒 |
| 按住 ±10 按钮 | 连续前进 / 后退 |
| 点击进度条 | 跳转到该位置 |
| 按住 / 拖动进度条 | 显示拖到的时间（分:秒），松手跳转 |
| 点击锁屏按钮 | 锁定控制键 |
| 长按右下角锁屏徽标 | 解锁 |

## 技术说明

- 纯静态页面：`index.html` + `styles.css` + `app.js`，无任何第三方依赖
- `manifest.webmanifest`：横屏方向、全屏显示、应用图标
- `sw.js`：Service Worker，应用外壳离线缓存
- 视频文件通过 `URL.createObjectURL` 在本地播放，不上传任何数据
